CURSOR × MAGPIE

让 Cursor 使用 Magpie 的模型

在 Magpie 管理供应商和用量，在 Cursor 中选择模型、对话和调用工具。

开始使用

  1. 在 Magpie 的 Agent 页面找到 CCursor，分配模型并打开连接开关。
  2. 停止原版 CCursor 服务。已有默认端口补丁时，可以继续使用已有客户端补丁。
  3. 启动或重启 Cursor，在模型选择器中选择刚分配的模型。

模型变更会自动同步。桥接服务监听 127.0.0.1:39831，请保持 Magpie 运行。

第一次给 Cursor 接入

如果 Cursor 从未安装 CCursor，关闭全部 Cursor 窗口后，在插件源码目录执行：

bun cli.ts setup --cursor-closed

此操作会备份并修改 Cursor 应用文件。安装插件本身不会修改它们。恢复命令：

bun cli.ts restore --cursor-closed

排查连接

在插件目录运行 bun cli.ts status 查看桥接状态。端口冲突通常表示原版 CCursor 仍在运行。详情见 Magpie 插件日志。
