CURSOR × MAGPIE

让 Cursor 使用 Magpie 的模型

在 Magpie 管理供应商和用量，在 Cursor 中选择模型、对话和调用工具。

开始使用

  1. 插件加载时会自动备份并安装 Cursor 接入补丁，无需手动运行安装命令。
  2. 在 Magpie 的 Agent 页面找到 CCursor，分配模型并打开连接开关。
  3. 启动 Cursor，选择刚分配的模型。如果安装插件时 Cursor 已经打开，重启一次让补丁生效。

模型变更会自动同步。桥接服务监听 127.0.0.1:39831，请保持 Magpie 运行。

自动接入与恢复

插件会保留原文件备份，已有完整补丁会直接复用。Cursor 更新后会重新检查接入状态。接入结果和需要处理的问题会显示在 Magpie 插件日志中。

如果本机还运行着原版 CCursor，请停止原服务并关闭其自动启动，保留安装文件即可。

需要恢复客户端文件时，关闭 Cursor，在插件源码目录执行：

bun cli.ts restore --cursor-closed

排查连接

在插件目录运行 bun cli.ts status 查看桥接状态。端口冲突通常表示原版 CCursor 仍在运行。详情见 Magpie 插件日志。

若自动接入未完成，日志会说明未找到 Cursor、权限不足或补丁不兼容等具体原因。
