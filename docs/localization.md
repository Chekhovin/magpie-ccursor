# Cursor 中文界面

`0.4.0` 起，插件在 Magpie 的 Agent 页底部提供「Cursor 中文界面」面板，默认开启。它使用 Magpie 官方的 `agents` 面板位置，没有新增侧栏页面，也不修改 Magpie 程序。当前 Magpie 尚未提供在单个 Agent 详情行之间插入控件的接口。

## 开启与关闭

1. 在 Magpie 的 Agent 页底部切换「Cursor 中文界面」。
2. 设置保存成功后，当前面板会自动刷新，让 Magpie 加载新选项。
3. 等待后台接入完成，再完全退出并重新打开 Cursor。通常只需几秒；正在备份或更新的文件需要更久。

此开关不影响 CCursor 的 Agent 连接、模型分配或对话数据库。关闭只撤销插件附加的翻译，保留模型接入补丁。已有 VS Code 中文语言包及显示语言设置不受修改，因此基础编辑器界面仍可能是中文。开关不是“卸载所有中文语言包”。

面板只能确认选项保存成功，不能读取客户端安装状态。若没有变化，请查看插件日志，或运行 `bun cli.ts status` 检查输出中的 `autoSetup.state` 和 `autoSetup.message`。该命令不直接显示汉化结果，具体查看方法见下方[选项与诊断](#选项与诊断)。

## 支持范围

目前附带的是 Cursor **3.27.22** 两份已验证 renderer 文件的翻译数据，覆盖普通 IDE 与 Agents 窗口。匹配条件同时包括版本号及原始文件 SHA-256；不同操作系统、不同构建或较新版本的文件若不匹配，会标记为 `unsupported` 并保留模型接入，不猜测新的字节位置。

首次安装时，缺少选项等同于开启。关闭后保存的 `false` 会跨 Magpie 重启和插件升级保留。Cursor 更新后，只为匹配翻译目录的新原件应用汉化；不匹配时等待后续适配。

## 来源与恢复

翻译来自用户提供并授权整合的既有 Cursor 界面汉化。提取时对比了同版本未汉化原始备份与去除接入补丁后的汉化备份，完成双向字节与哈希验证。没有打包完整 Cursor 文件或用户配置。

原有汉化中发现四处内部标识替换：两个窗口的拖放类型 `Files` 和库导出属性 `Hooks`。本插件的目标汉化版本保留这些内部标识的英文值，其余现有翻译继续沿用。旧汉化基线可以识别并转换，不能把先前正常使用当作所有翻译语义均已验证的证据。

汉化仅从已验证的原始备份生成，随后由正常安装器重新安装接入补丁并计算产品校验和。切换前保存当前文件用于失败回滚，最初的 `.original` 备份不会被替换。

关闭开关与执行 `restore` 不同：

- **关闭汉化**：生成未附加汉化的 renderer，并保留 CCursor 接入功能。
- **`bun cli.ts restore --cursor-closed`**：还原本插件第一次记录的客户端文件，并暂停自动接入。若最初备份本来就是汉化文件，完整恢复会保留那份原有汉化。

外部改动、损坏的备份或不完整的安装会停止切换并保留证据；不会通过修改清单哈希来接受未知文件。

## 选项与诊断

Magpie 保存插件自己的 `options.localize`。插件宿主将有效布尔值同步到 `~/.magpie-ccursor/plugin-options.json`，守护进程每次轮询读取它；无需编辑 Agent 的 `connection.json`。

自动接入完成并记录汉化结果后，可在 `~/.magpie-ccursor/auto-setup.json` 的 `localization.state` 中查看 `enabled`、`disabled` 或 `unsupported`；接入失败或暂停时，`localization` 可能不存在。该文件及补丁清单中的 `localization` 还记录请求值和词条修订。手动恢复后的暂停状态不会被开关覆盖；需要重新接入时，关闭 Cursor 后明确执行 `setup`。
